# 西门子 S7-1200 PID 控制实战

## 前言

PID 控制是工业自动化中最常用的闭环控制算法。S7-1200 内置了高质量的 PID 指令库，本文带你从零掌握它。

## 1. PID 基本原理回顾

PID = **P**roportional（比例）+ **I**ntegral（积分）+ **D**erivative（微分）

$$u(t) = K_p \cdot e(t) + K_i \int e(t)dt + K_d \frac{de(t)}{dt}$$

- **P（比例）**：当前误差的立即响应，增大 Kp 加快响应但可能振荡
- **I（积分）**：消除稳态误差，增大 Ki 消除静差但降低稳定性
- **D（微分）**：预测误差趋势，增大 Kd 减少超调但对噪声敏感

## 2. TIA Portal 中的 PID 指令块

S7-1200 提供两种 PID 指令块：

| 指令块 | 适用场景 |
|--------|----------|
| `PID_Compact` | 通用 PID，自带自整定功能 |
| `PID_3Step` | 带执行器的三步控制（阀门等） |

### 添加 PID_Compact 指令

1. 在 TIA Portal 中打开程序块 OB1
2. 在指令库中找到「Technology → PID Control → Compact PID」
3. 拖入到 OB1 循环调用

```
// OB1 中的调用示例
"PID_Compact_DB"(
    Setpoint := #SP_Temperature,   // 设定值（°C）
    Input := #PV_Temperature,      // 过程值（来自模拟量输入）
    Output => #MV_HeaterPower,     // 操纵量（0.0~1.0）
    ManualEnable := FALSE,
    Reset := #Reset_PID
);
```

## 3. 参数自整定步骤

1. 确认系统稳定在手动模式
2. 在 PID 调试面板中点击「启动自整定」
3. 系统自动施加阶跃扰动，记录响应曲线
4. 自整定完成后，自动填入 Kp/Ti/Td 参数
5. 切换到自动模式，观察控制效果

> **注意**：自整定需要系统处于可施加扰动的工作状态，建议在设备空载时进行。

## 4. 典型应用：烤箱温度控制

**系统参数**：
- 设定温度：200°C
- 热电偶输入：AI 通道 0（4-20mA → 0-300°C）
- 加热功率输出：AO 通道 0（4-20mA → 0-100%）

**整定结果参考**（实际需自整定）：

| 参数 | 参考值 | 说明 |
|------|--------|------|
| Kp | 2.5 | 比例增益 |
| Ti | 120 s | 积分时间 |
| Td | 15 s | 微分时间 |

## 5. 常见问题

**Q: 自整定失败怎么办？**
检查 Input/Output 量程配置，确保过程变量在量程范围内，手动给一个阶跃扰动验证系统响应。

**Q: 输出一直在最大值？**
可能是 Kp 过大或 Setpoint 设置过高。先切手动降低 Setpoint，再重新整定。
